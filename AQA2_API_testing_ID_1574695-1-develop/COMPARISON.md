# Сравнение ручного и AI-assisted решения

## Task 1: OkHttp (manual-solution) - сделано вручную
- ✅ Классы User, UserListResponse, UserSingleResponse, Support созданы вручную
- ✅ Jackson для сериализации
- ✅ Тесты написаны вручную
- ⏱️ Время: ~2 часа

## Task 2: REST-Assured (ai-assisted-solution) - с помощью AI

### Что AI сделал хорошо:
1. ✅ Преобразовал DTO в Java Records
2. ✅ Правильно расставил аннотации @JsonProperty
3. ✅ Сгенерировал базовую структуру тестов
4. ✅ Экономия времени: ~50%

### Ошибки AI:
1. ❌ Неправильно обработал null значения
2. ❌ Добавил лишние зависимости
3. ❌ Не учел, что нужно игнорировать неизвестные поля

### Исправления вручную:
1. Добавил `DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES = false`
2. Исправил обработку null в Record
3. Добавил задержки между тестами

## Task 3: Retrofit (ai-assisted-solution) - с помощью AI

### Что AI сделал хорошо:
1. ✅ Сгенерировал интерфейс ApiService с аннотациями
2. ✅ Правильно создал методы для всех HTTP операций
3. ✅ Экономия времени: ~40%

### Ошибки AI:
1. ❌ Забыл добавить аннотацию @Path для параметров
2. ❌ Неправильно указал типы возвращаемых значений
3. ❌ Не добавил обработку ошибок

### Исправления вручную:
1. Добавил `@Path("id")` к методам
2. Исправил типы возвращаемых значений
3. Добавил логирование запросов

## Выводы:
1. AI хорошо справляется с рутинными задачами (генерация DTO, интерфейсов)
2. AI часто ошибается в деталях (аннотации, типы данных)
3. Без проверки человека AI-код не работает
4. Экономия времени: ~40-50%
5. Лучший подход: сначала сделать руками, потом использовать AI для оптимизации
